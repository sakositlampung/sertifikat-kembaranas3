Panduan Hosting GitHub Pages & Database Firebase

GitHub Pages:

  1. Buat repository baru bernama sertifikat-kembaranas.
  2. Simpan kode file ini sebagai index.html.
  3. Upload file ke repository, lalu masuk ke Settings > Pages.
  4. Pilih Branch main lalu klik Save.

Firebase Firestore:

  1. Buka Firebase Console → buat Cloud Firestore.
  2. Sistem otomatis menyimpan data sertifikat pada path: /certificates/{id}.
  3. Mendukung verifikasi langsung saat QR Code di-scan dari HP peserta.
