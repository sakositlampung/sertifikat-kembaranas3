Panduan Deployment ke GitHub Pages & Firebase

Petunjuk lengkap untuk mempublikasikan aplikasi sertifikat ini secara online agar bisa diakses oleh siapa saja saat scan QR Code.

1. Hosting Gratis Menggunakan GitHub Pages
  1. Buat akun GitHub dan buat Repository baru dengan nama contoh: sertifikat-kembaranas.
  2. Simpan file ini sebagai index.html.
  3. Upload file index.html ke repository GitHub tersebut.
  4. Buka tab Settings > Pages pada repository Anda.
  5. Pada bagian Build and deployment, pilih Branch: main / root lalu klik Save.
  6. Website Anda akan aktif di URL: https://username.github.io/sertifikat-kembaranas/.
2. Integrasi Firebase Firestore (Database Online)
  1. Buka Firebase Console lalu buat project baru.
  2. Aktifkan Firestore Database dan pilih mode Test / Public rules.
  3. Aplikasi ini secara otomatis mendeteksi Firebase Config jika dipasang di script.
  4. Seluruh data sertifikat, nomor urut, dan QR Code akan tersimpan di cloud secara realtime!
